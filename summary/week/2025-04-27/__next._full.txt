1a:Ta39,## Pull Request: Add Livepeer LLM Inference Plugin to Eliza Framework

### Description
This PR introduces the **Livepeer LLM Inference Plugin** for the Eliza framework. It enables language-model inference via Livepeer’s API gateway, allowing agents to leverage a variety of models without requiring individual API keys.

---

### Features
- **LLM Inference Processing**  
  Seamless POST requests to Livepeer’s `/llm` endpoint for chat-style interactions.
- **Multi-Model Support**  
  Automatically selects from small or large models, or custom endpoints, based on configuration.
- **Zero-Key Integration**  
  No need for proprietary API keys—uses gateway defaults or runtime settings.

---

### Implementation Details
- **New Package**  
  Added `packages/plugin-livepeer-inference/` containing the TypeScript plugin and Zod schema.
- **Config Schema**  
  Validates and parses:  
  - `LIVEPEER_GATEWAY_URL`  
  - Optional model overrides (`LIVEPEER_MODEL`, `LIVEPEER_LARGE_MODEL`)  
  - Runtime overrides for `temperature` and `maxTokens`
- **Core Logic**  
  - `callLivepeerLLM()` helper builds messages and handles HTTP calls  
  - Exposes three hooks under `ModelType`:  
    - `TEXT_SMALL`  
    - `TEXT_LARGE`  
    - `TEXT_EMBEDDING` (character-code embedding fallback)

---

### Setup & Usage
1. **Install**  
   ```bash
   pnpm install packages/plugin-livepeer-inference
   ```
2. **Configure**  
   - Add your gateway URL in `.env` or runtime settings:  
     ```env
     LIVEPEER_GATEWAY_URL=https://your-gateway.livepeer.com
     LIVEPEER_MODEL=meta-llama/Meta-Llama-3.1-8B-Instruct
     ```
   - (Optional) Override temperature or max tokens:  
     ```env
     LIVEPEER_TEMPERATURE=0.7
     LIVEPEER_MAX_TOKENS=1024
     ```
3. **Enable**  
   Include `"plugin-livepeer-inference"` in your agent’s `plugins` array.

---

### Testing
- **Test Suite**:  
  - Core inference flows covered under `packages/plugin-livepeer-inference/tests/*`  
  - Zod schema validation tests for missing/invalid config
- **Integration**:  
  Verified against [[UD1sto/elizav2-livepeer](https://github.com/UD1sto/elizav2-livepeer)](https://github.com/UD1sto/elizav2-livepeer)
- **Known Issue**:  
  - Intermittent `503 Gateway` errors on reflection LLM calls from the bootstrap plugin. Under investigation; core flow still completes successfully.

---
