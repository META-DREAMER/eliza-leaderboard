ElizaOS's development on July 13, 2025, primarily focused on the elizaos/eliza repository, with significant advancements in core stability, developer experience, and automation capabilities. Key achievements include critical bug fixes across build processes, CLI commands, and database operations, alongside a new feature enabling Claude workflow access on every commit and expanded bash/GitHub CLI access for Claude workflows. The day also saw improvements in testing infrastructure and the initiation of a new scenario runner feature.

✅ Completed Work

Core Stability and Build Process Enhancements

  • Resolved an issue where tsup incorrectly wiped vite builds, ensuring proper build order and integrity (elizaos/eliza#5555).
  • Fixed a bug affecting advisory lock acquisition in the SQL plugin, enhancing database operation reliability (elizaos/eliza#5572).
  • Updated core tests to streamline workflows, improve configuration management, and enhance local AI support by replacing execa and local-ai with bun runtime and Ollama (elizaos/eliza#5556).

CLI Improvements and User Experience

  • Deployed a fix to suppress redundant "update available" messages during the update command execution (elizaos/eliza#5567).
  • Updated CLI test expectations for version 1.2.1, specifically addressing monorepo detection in update command tests (elizaos/eliza#5561).

Claude Workflow and Automation Enhancements

  • Added a new feature allowing Claude code review workflows to run on every commit to PRs, not just on open/ready states (elizaos/eliza#5570).
  • Granted both Claude workflows full bash and GitHub CLI command access, expanding automation possibilities (elizaos/eliza#5570).
  • Performed related refactoring to clarify and robustify plugin ordering tests (elizaos/eliza#5557).
