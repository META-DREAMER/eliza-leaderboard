# Background

## What does this PR do?

This PR improves the voice model selection by enhancing how plugins are managed when changing between voice model providers. Specifically:

1. Makes voice model to plugin mapping configurable in voice-models.ts
2. Ensures only one voice-related plugin is active at a time (removes previous provider's plugin when switching)
3. Improves the UI to clearly indicate which plugins are required by the selected voice model
4. Prevents users from removing plugins that are required by the current voice model

## What kind of change is this?

Improvements (enhancement to existing voice model selection and plugin management features)

# Documentation changes needed?

My changes do not require a change to the project documentation.

# Testing

## Where should a reviewer start?

1. packages/client/src/config/voice-models.ts - Added configurable provider-to-plugin mapping
2. packages/client/src/components/character-form.tsx - Updated voice model selection logic
3. packages/client/src/components/plugins-panel.tsx - Enhanced UI for plugin management

## Detailed testing steps

1. Create a new character or edit an existing one
2. Select a local voice model (e.g., "Local Voice - Female 1")
   - Verify the Local AI plugin is automatically added
   - Verify the plugin appears with a green background in the plugins panel

3. Switch to an ElevenLabs voice model (e.g., "ElevenLabs - Rachel")
   - Verify the Local AI plugin is automatically removed
   - Verify the ElevenLabs plugin is automatically added
   - Verify only one voice-related plugin is present
   - Verify a toast notification appears about the plugin update

4. Try to remove the ElevenLabs plugin
   - Verify it can't be removed while the ElevenLabs voice model is selected
   - Verify a toast notification appears explaining why it can't be removed

5. Switch back to a local voice model

   - Verify only one voice-related plugin is present

# Background

## What does this PR do?

This PR improves the voice model selection by enhancing how plugins are managed when changing between voice model providers. Specifically:

1. Makes voice model to plugin mapping configurable in voice-models.ts
2. Ensures only one voice-related plugin is active at a time (removes previous provider's plugin when switching)
3. Improves the UI to clearly indicate which plugins are required by the selected voice model
4. Prevents users from removing plugins that are required by the current voice model

## What kind of change is this?

Improvements (enhancement to existing voice model selection and plugin management features)

## Detailed testing steps
