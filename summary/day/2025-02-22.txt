14:T6af,# Add Paradex DEX Plugin

## Overview
This PR introduces a new plugin for Eliza OS that enables integration with the Paradex decentralized exchange. The plugin provides comprehensive functionality for trading operations, market data access, and account management through natural language commands.

## Description
The Paradex plugin implements core functionality for interacting with the Paradex DEX, including:

- Real-time market data access and monitoring
- Order management (place/cancel)
- Position tracking
- Account balance monitoring
- Watchlist management
- Authentication and onboarding flows

### Key Components

#### Providers
- `bboProvider`: Best bid/offer data streaming
- `marketDataProvider`: Available markets information
- `balanceParadexProvider`: Account balance tracking
- `openOrdersProvider`: Order management and tracking
- `openPositionsProvider`: Position tracking and management

#### Actions
- `manageWatchlistAction`: Add/remove markets from watchlist
- `placeOrderAction`: Execute trades
- `cancelOrderAction`: Cancel existing orders
- `onboardingAction`: User onboarding flow

### Architecture Decisions
- Implemented JWT-based authentication flow
- Used TypeScript for type safety
- Followed modular design pattern for extensibility
- Added comprehensive error handling
- Included detailed logging for debugging


### Dependencies
- `@elizaos/core`: ^0.1.7
- `date-fns`: ^4.1.0
- `starknet`: ^5.24.3

## Documentation
- Added comprehensive README
- Included inline documentation
- Added TypeScript types and interfaces
- Documented environment variables

# Background

## What does this PR do?
This PR removes the dependency on Langchain’s `RecursiveCharacterTextSplitter` and implements an internal text-splitting function within ElizaOS Core. By consolidating this functionality, we reduce external dependencies, improve maintainability, and avoid potential versioning issues with Langchain. The new implementation ensures consistent text chunking while maintaining the existing API structure.

## What kind of change is this?
This is mostly a refactor change in ElizaOS core to not use a heavy dependency like langchain for a small task of splitting text.
