4:T60c,**Describe the bug**

`parseJSONObjectFromText` broke for me in or before 0.25.9
It was working OK for me in 0.18

The problem imo is the `normalizeJSONString` function.

**To Reproduce**

1. Run `node` interpreter in your eliza repo.
2. Run the following:
```
const { parseJSONObjectFromText, cleanJsonResponse } = await import("@elizaos/core");

let text = '```json{    "success": true,    "result": {        "serviceAdCID": "zdpuB1ZVfhZFX4iaVhXkyhTuGUhPA1Ac3LuQdSWe9zcdXrKce",        "wallet": "9ovkK7WoiSXyEJDM5cZG3or3W95bdzZLDDHhuMgSJT9U",        "desiredServiceID": "Landing Page Creation",        "desiredUnitAmount": "1"    }}```'

parseJSONObjectFromText(text)
```
You will see an error, and then the code tries to handle it by doing `extractAttributes(text)`
But `extractAttributesText` cannot handle nested objects.

![Image](https://github.com/user-attachments/assets/2cb0d3bc-c662-4f4b-b3b3-59ab0e2f02a0)

**Expected behavior**

In my opinion, running the text through `cleanJsonResponse` and then `JSON.parse` should be enough, as `JSON.parse` handles a lot of the stuff that `normalizeJSONString` is trying to handle.

Additionally, the code should fail if `JSON.parse` can't parse it, instead of trying to fix the problem with `extractAttributesText`.
That way the user can fix their AI prompt.

![Image](https://github.com/user-attachments/assets/da93c13d-ede8-4e50-bc83-5e069dfa36b3)

16:T60c,**Describe the bug**

`parseJSONObjectFromText` broke for me in or before 0.25.9
It was working OK for me in 0.18

The problem imo is the `normalizeJSONString` function.

**To Reproduce**

1. Run `node` interpreter in your eliza repo.
2. Run the following:
```
const { parseJSONObjectFromText, cleanJsonResponse } = await import("@elizaos/core");

let text = '```json{    "success": true,    "result": {        "serviceAdCID": "zdpuB1ZVfhZFX4iaVhXkyhTuGUhPA1Ac3LuQdSWe9zcdXrKce",        "wallet": "9ovkK7WoiSXyEJDM5cZG3or3W95bdzZLDDHhuMgSJT9U",        "desiredServiceID": "Landing Page Creation",        "desiredUnitAmount": "1"    }}```'

parseJSONObjectFromText(text)
```
You will see an error, and then the code tries to handle it by doing `extractAttributes(text)`
But `extractAttributesText` cannot handle nested objects.

![Image](https://github.com/user-attachments/assets/2cb0d3bc-c662-4f4b-b3b3-59ab0e2f02a0)

**Expected behavior**

In my opinion, running the text through `cleanJsonResponse` and then `JSON.parse` should be enough, as `JSON.parse` handles a lot of the stuff that `normalizeJSONString` is trying to handle.

Additionally, the code should fail if `JSON.parse` can't parse it, instead of trying to fix the problem with `extractAttributesText`.
That way the user can fix their AI prompt.

![Image](https://github.com/user-attachments/assets/da93c13d-ede8-4e50-bc83-5e069dfa36b3)
