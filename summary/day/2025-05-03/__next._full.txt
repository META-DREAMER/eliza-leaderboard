# Background

## What does this PR do?

Fixes TypeScript type resolution by properly generating declaration files in the correct format. The package was generating CommonJS type declarations while using ESM for JavaScript code, causing TypeScript to fail to resolve types through ESM exports.

This issue affects any TypeScript project that:
- Uses ESM imports
- Has strict TypeScript configurations
- Relies on proper type resolution from dependencies
