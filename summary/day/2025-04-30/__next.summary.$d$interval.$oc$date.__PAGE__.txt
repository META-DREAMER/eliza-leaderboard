      "shared": true
    }
  ],

   - "invalid byte sequence for encoding "UTF8": 0x00"
   - "Circuit breaker is OPEN"
   - "unsupported Unicode escape sequence"

- PDF files should be properly processed without encoding errors
- Knowledge processing should complete successfully
- Circuit breaker should handle failures gracefully without blocking all operations
