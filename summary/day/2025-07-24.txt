14:T2e7f,**Describe the bug**

The agent created using `elizaos create <agentname>` on Windows WSL does not respond to messages in the front-end GUI. When I send the message "hello, what's your name?" to the default agent, there is no response from the agent.

**To Reproduce**

1. Set up ElizaOS in a Windows WSL environment.
2. Create an agent using the command: `elizaos create <agentname>`.
3. Set up the Google Generative AI API key in the environment.
4. Run `elizaos start` to start the project.
5. Open the front-end GUI and send the message "hello, what's your name?" to the default agent.

**Expected behavior**

The agent should respond to the message "hello, what's your name?" with a greeting or answer.
