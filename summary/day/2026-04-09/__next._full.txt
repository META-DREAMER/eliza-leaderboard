14:T2760,## Overview

Brings the ElizaOS Discord plugin significantly closer to OpenClaw feature parity. Battle-tested on a live milady agent (nyx) running on dedicated hardware with local LLM inference.

## Phase 1: Core UX (P0)

### New Files
- **`typing.ts`** — Typing indicator with 9s heartbeat, 20min TTL, auto-stop
- **`status-reactions.ts`** — Emoji lifecycle (⏳→🤔→✅/❌), scope gating (all/group-mentions/none), serialized API calls
- **`debouncer.ts`** — Coalesces rapid messages per author+channel (400ms window), attachment bypass
- **`inbound-envelope.ts`** — Structured metadata context: `[Discord #channel | Server] @user (timestamp): message`
- **`reasoning-tags.ts`** — Strips `<thinking>`, `<reasoning>`, `<STOP/>` and other model artifacts from output

### Bug Fixes
- Voice manager cleanup (was empty `if` block in `stop()`)
- Login failure health reporting (`isHealthy()` method)
- DM policy default changed from `open` to `pairing`

## Phase 2: Advanced Features

### New Files
- **`draft-stream.ts`** (286 lines) — Edit-based progressive responses with rate limit throttling (1.2s), deleted message handling, multi-message overflow
- **`draft-chunking.ts`** (72 lines) — Smart text splitting on sentence/paragraph boundaries
- **`slash-commands.ts`** (546 lines) — Full command registry with 6 built-in commands:
  - `/help` — List all commands
  - `/status` — Uptime, memory, guilds
  - `/search` — Channel history search
  - `/clear` — Reset conversation context
  - `/settings` — View bot configuration
  - `/model` — View/switch model with autocomplete
