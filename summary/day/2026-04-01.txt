14:T833,## What

  A `plugin-maxia` that lets any ElizaOS agent access the [MAXIA](https://maxiaworld.app) AI-to-AI marketplace natively
  — buy/sell AI services, swap tokens across 7 chains, and rent GPUs.

  ## Why

  ElizaOS agents currently lack a unified marketplace to transact with other AI agents. MAXIA is a live AI-to-AI
  marketplace on 14 blockchains with on-chain USDC escrow (Solana + Base), 65 token swaps, and GPU rental via Akash
  Network.

  ## Plugin capabilities

  - **AI Services** — discover, buy, and sell AI services (text, code, audit, data analysis) with USDC escrow protection
  - **Token Swap** — swap 65 tokens across 7 chains (Jupiter on Solana, 0x on 6 EVM chains)
  - **GPU Rental** — rent A100/H100/RTX GPUs via Akash Network (15-40% cheaper than AWS)
  - **Wallet Analytics** — portfolio tracking, PnL, DeFi yield scanning
  - **Price Oracle** — real-time prices from Pyth Network SSE (<1s latency)
  - **AIP Protocol** — signed intent envelopes (ed25519) for secure agent-to-agent transactions

  ## Integration approach

  The plugin would wrap MAXIA's 559 REST API endpoints + 46 MCP tools as ElizaOS actions and providers:

  ```typescript
  // Example actions
  MAXIA_SWAP        // swap tokens across 7 chains
  MAXIA_BUY_SERVICE // purchase an AI service with escrow
  MAXIA_RENT_GPU    // rent GPU compute
  MAXIA_GET_PRICE   // real-time token price
  MAXIA_DISCOVER    // find AI services on marketplace

  Status

  MAXIA is live in production with deployed smart contracts:
  - Solana escrow: 8ADNmAPDxuRvJPBp8dL9rq5jpcGtqAEx4JyZd1rXwBUY
  - Base escrow: 0xBd31bB973183F8476d0C4cF57a92e648b130510C

  We're happy to build and maintain the plugin. Looking for feedback on the approach before submitting a PR.

  Related Problem

  ElizaOS agents that need to purchase compute, trade tokens, or use AI services must integrate each provider separately
   (Jupiter, Akash, individual AI APIs). A marketplace plugin would give agents one-stop access through a single
  interface, with built-in escrow protection for trustless agent-to-agent commerce.15:Tda0,## New Plugins
