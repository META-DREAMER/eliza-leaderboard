This PR introduces middleware support to the AgentServer, enhancing its flexibility and customization.

**Summary of changes:**

- **Added Middleware Support:**
    - Introduced `ServerMiddleware` interface to define the structure for custom middleware functions.
    - Implemented `ServerOptions` interface to allow passing an array of middleware functions during `AgentServer` initialization.
    - Modified the `AgentServer` constructor to accept `ServerOptions` and integrate provided middleware into the Express application using `app.use()`.

- **Benefits of Middleware:**
    - **Extensibility:** Enables users to inject custom logic into the request processing pipeline, such as authentication, logging, and request modification, without altering the core `AgentServer` code.
    - **Modularity:** Promotes a more modular design by separating concerns and allowing for reusable middleware components.
    - **Customization:** Offers greater control over the server's behavior, allowing developers to tailor it to specific application requirements.

- **Example Usage:**
```typescript
import { AgentServer, ServerMiddleware } from './path/to/agent-server'; // Adjust path

const customMiddleware: ServerMiddleware = (req, res, next) => {
  console.log('Request URL:', req.url);
  next();
};

const server = new AgentServer({
  middlewares: [customMiddleware],
});

server.start();
```

- **Minor Refactor:**
    - Updated media serving paths to use `/media/uploads` and `/media/generated` for better organization.

- **Removed Endpoints:**
    - Removed the `/image`, `/fine-tune`, and `/speak` endpoints from the `AgentServer` class. These endpoints may be relocated to other modules or are no longer part of the core server functionality in this PR.

This PR significantly improves the `AgentServer` by making it more adaptable and extensible through the introduction of middleware support. This allows for a more flexible and powerful agent server architecture.
