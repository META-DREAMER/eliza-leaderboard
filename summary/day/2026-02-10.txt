Add **plugin-signet** — enables ElizaOS agents to buy spotlight ads on [Signet](https://signet.sebayaki.com) with USDC via [x402](https://x402.org) micropayments on Base.

## What is Signet?

Signet is an onchain advertising platform on Base. Users pay USDC to place their URL in the spotlight section, where it gets thousands of views and clicks. Unlike auction-based alternatives (~$300+/day minimum), Signet uses fixed pricing — post instantly for ~$12 USDC.

**Key stats:** 126 ads placed, average 400+ clicks per placement, 1000+ daily visitors.

## Actions

| Action | Description | Wallet Required |
|--------|-------------|:---:|
| `SIGNET_ESTIMATE` | Check current spotlight pricing and availability | No |
| `SIGNET_POST_SPOTLIGHT` | Pay USDC to place a URL on the spotlight | Yes |

## Provider

| Provider | Description |
|----------|-------------|
| `SIGNET_SPOTLIGHT_STATUS` | Injects current pricing into agent context |

## How it works

1. Agent POSTs to `/api/x402/spotlight` → receives `402 Payment Required` with price
2. Plugin signs EIP-3009 `transferWithAuthorization` for USDC on Base
3. Plugin resends with `X-PAYMENT` header containing signed authorization
4. Signet settles USDC transfer and executes onchain Zap
5. URL appears in spotlight ✅

All payments onchain on Base. No API keys, no accounts — just a wallet with USDC.

## Configuration

```env
SIGNET_PRIVATE_KEY=0x...  # Any EVM key with USDC on Base
# Also accepts BASE_PRIVATE_KEY or EVM_PRIVATE_KEY
```
