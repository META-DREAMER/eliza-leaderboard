## Background

### What does this PR do?

This PR adds support for parameterized routes (Express-style) in the plugin middleware.

Currently, the plugin routing middleware only supports two types of routes:
1. Exact routes (strict matching)
2. Wildcard routes like `/assets/*`

It lacks support for parameterized routes like `/documents/:knowledgeId` or `/toto/:id/tata/:id`.

This PR adds the necessary logic to:
- Convert Express-style routes with parameters to regular expressions
- Extract parameter values from actual paths
- Populate `req.params` with these values
- Pass to the appropriate handler

Bug fixes (non-breaking change which fixes an issue)
