<!-- Discord username: 0xbbjoker -->15:Tc8b,## 🔧 Fix: Type Export Issues in @elizaos/core Package

### Problem
The deployed version of `@elizaos/core` on NPM was experiencing type export failures, causing TypeScript compilation errors when the package was used outside the monorepo. Users reported errors like:
```
Module '"@elizaos/core"' has no exported member 'Agent'
Module '"@elizaos/core"' has no exported member 'UUID'
... (174+ similar errors)
```

### Root Cause Analysis
1. **Missing Source Files**: The published NPM package only included the `dist` folder, but the type declaration files referenced source files in `../src` that weren't included in the package
2. **Broken Type Generation**: The build process was attempting to generate TypeScript declarations using `npx tsc` which wasn't available in the build environment
3. **Incorrect Build Script**: The `build.ts` script created stub `.d.ts` files that pointed to non-existent locations

### Solution Implemented

#### 1. Fixed `package.json` exports and files
```diff
  "files": [
-   "dist"
+   "dist",
+   "src"
  ],
```

#### 2. Updated `build.ts` to generate proper type declaration stubs
```typescript
// dist/index.d.ts
export * from '../src/index.node';

// dist/node/index.d.ts  
export * from '../../src/index.node';

// dist/browser/index.d.ts
export * from '../../src/index.browser';
```

#### 3. Created `tsconfig.build.json` for future TypeScript compilation
```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "declaration": true,
    "declarationMap": true,
    "emitDeclarationOnly": true,
    "outDir": "./dist",
    "rootDir": "./src"
  }
}
```

### Verification
✅ **Monorepo Development**: Types resolve correctly through source references
✅ **NPM Package**: Published package includes source files for type resolution
✅ **Build Output Structure**:

│   └── index.node.js  # Compiled bundle

    ├── index.d.ts     # → ../../src/index.browser

```

```
