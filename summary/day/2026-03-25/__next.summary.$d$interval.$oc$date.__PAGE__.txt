**Category:** Blockchain / Web3 data
**npm package:** (to be published as `@elizaos/plugin-walletiq`)

### What it does

[WalletIQ](https://walletiq.dev) is a one-call wallet intelligence API for EVM addresses. It returns:

- **Wallet age** + first/last activity timestamps  
- **DeFi protocol usage** (75+ protocols: Uniswap, AAVE, Pendle, Morpho, Curve, etc.)  
- **Risk score** (0–100)  
- **Behavioral labels** (DeFi power user, NFT trader, bot-likely, dormant, etc.)  
- **Chains:** Ethereum, Base, Optimism, Polygon, Arbitrum

### Why it belongs in ElizaOS

Agents routinely interact with other wallets — sending payments, delegating decisions, accepting bids. WalletIQ gives any Eliza agent a `profileWallet` action to assess counterparty risk before committing to a transaction.

```typescript
// Example action usage:
// User: "Is 0xd8dA... a trustworthy counterparty?"
// Agent calls profileWallet("0xd8dA...") → returns risk score, DeFi history, labels
```

### Payment model

The endpoint is crypto-native (x402, USDC on Base, $0.005/call) — no API key, no signup, agent-native. There's also a free API key tier (100 calls/day) for dev/test.

### Plugin sketch

```typescript
import type { Plugin, Action } from "@elizaos/core";

const profileWalletAction: Action = {
  name: "PROFILE_WALLET",
  description: "Profile an EVM wallet address for risk, DeFi history, and behavioral labels",
  examples: [],
  handler: async (runtime, message, state, options, callback) => {
    const address = extractAddress(message.content.text);
    const res = await fetch(`https://walletiq.dev/api/v1/profile/${address}`, {
      headers: { Authorization: `Bearer ${runtime.getSetting("WALLETIQ_API_KEY")}` },
    });
    const profile = await res.json();
    callback?.({
      text: `Wallet ${address}: risk score ${profile.risk_score}/100, active since ${profile.wallet_age_days} days, uses ${profile.defi_protocols?.length ?? 0} DeFi protocols.`,
      data: profile,
    });
  },
};

export const walletiqPlugin: Plugin = {
  name: "walletiq",
  description: "Wallet intelligence API — profile any EVM address for risk, DeFi usage, and behavioral labels",
  actions: [profileWalletAction],
};
```

17:T9b1,## Plugin request: WalletIQ

**Category:** Blockchain / Web3 data
**npm package:** (to be published as `@elizaos/plugin-walletiq`)

### What it does

[WalletIQ](https://walletiq.dev) is a one-call wallet intelligence API for EVM addresses. It returns:

- **Wallet age** + first/last activity timestamps  
- **DeFi protocol usage** (75+ protocols: Uniswap, AAVE, Pendle, Morpho, Curve, etc.)  
- **Risk score** (0–100)  
- **Behavioral labels** (DeFi power user, NFT trader, bot-likely, dormant, etc.)  
- **Chains:** Ethereum, Base, Optimism, Polygon, Arbitrum

### Why it belongs in ElizaOS

Agents routinely interact with other wallets — sending payments, delegating decisions, accepting bids. WalletIQ gives any Eliza agent a `profileWallet` action to assess counterparty risk before committing to a transaction.

```typescript
// Example action usage:
// User: "Is 0xd8dA... a trustworthy counterparty?"
// Agent calls profileWallet("0xd8dA...") → returns risk score, DeFi history, labels
```

### Payment model

The endpoint is crypto-native (x402, USDC on Base, $0.005/call) — no API key, no signup, agent-native. There's also a free API key tier (100 calls/day) for dev/test.

### Plugin sketch

```typescript
import type { Plugin, Action } from "@elizaos/core";

const profileWalletAction: Action = {
  name: "PROFILE_WALLET",
  description: "Profile an EVM wallet address for risk, DeFi history, and behavioral labels",
  examples: [],
  handler: async (runtime, message, state, options, callback) => {
    const address = extractAddress(message.content.text);
    const res = await fetch(`https://walletiq.dev/api/v1/profile/${address}`, {
      headers: { Authorization: `Bearer ${runtime.getSetting("WALLETIQ_API_KEY")}` },
    });
    const profile = await res.json();
    callback?.({
      text: `Wallet ${address}: risk score ${profile.risk_score}/100, active since ${profile.wallet_age_days} days, uses ${profile.defi_protocols?.length ?? 0} DeFi protocols.`,
      data: profile,
    });
  },
};

export const walletiqPlugin: Plugin = {
  name: "walletiq",
  description: "Wallet intelligence API — profile any EVM address for risk, DeFi usage, and behavioral labels",
  actions: [profileWalletAction],
};
```
