## Solution

### 1. Self-message hard skip (TypeScript)

Added a pre-LLM guard that skips messages from the agent itself (`message.entityId === runtime.agentId`). This fires before any LLM call, saving API costs and preventing self-response loops.

### 2. Stronger negative pressure in shouldRespond prompt

Added 4 new rules to the `shouldRespondTemplate` that push the LLM toward IGNORE in ambiguous group scenarios:

- **"do NOT respond to casual conversation between other users"** — stops the agent from inserting itself into human-to-human chat

- **"if {{agentName}} responded to the last 2+ messages in a row, stop and let others talk"** — anti-domination guard
- **"if nobody mentioned {{agentName}} or asked a direct question, IGNORE"** — strongest filter for ambient messages

These complement the existing 6 rules without changing the response format or evaluation flow.
