Versions of the package black before 24.3.0 are vulnerable to Regular Expression Denial of Service (ReDoS) via the lines_with_leading_tabs_expanded function in the strings.py file. An attacker could exploit this vulnerability by crafting a malicious input that causes a denial of service.

##### Highlights

This release is a milestone: it fixes Black's first CVE security vulnerability. If you

This release also fixes a bug in Black's AST safety check that allowed Black to make
incorrect changes to certain f-strings that are valid in Python 3.12 and higher.

    of Black would incorrectly format the contents of certain unusual f-strings containing
    nested strings with the same quote type. Now, Black will crash on such strings until
    support for the new f-string syntax is implemented. ([#&#8203;4270](https://redirect.github.com/psf/black/issues/4270))

interface IDatabase {

interface IRecordManager<T> {

  update(id: string, data: Partial<T>): Promise<void>;
  get(id: string): Promise<T>;

  address: string;

class RecommenderManager implements IRecordManager<Recommender> {

  async create(data: Recommender): Promise<void> {
    await this.db.query('INSERT INTO recommenders ...', [/* params */]);
  }
  
  async update(id: string, data: Partial<Recommender>): Promise<void> {
    await this.db.query('UPDATE recommenders ...', [/* params */]);
  }
  
  async get(id: string): Promise<Recommender> {
    return this.db.query('SELECT * FROM recommenders WHERE id = $1', [id]);
  }
}

class TokenManager implements IRecordManager<Token> {
  constructor(private db: IDatabase) {}
  // ... token-specific operations

// Main database instance with managers
class TrustDatabase {

    this.tokens = new TokenManager(db);
  }

  // Database-wide operations
  async migrate(): Promise<void> {
    await this.db.migrate();
  }
}

Versions of the package black before 24.3.0 are vulnerable to Regular Expression Denial of Service (ReDoS) via the lines_with_leading_tabs_expanded function in the strings.py file. An attacker could exploit this vulnerability by crafting a malicious input that causes a denial of service.

##### Highlights

This release is a milestone: it fixes Black's first CVE security vulnerability. If you

This release also fixes a bug in Black's AST safety check that allowed Black to make
incorrect changes to certain f-strings that are valid in Python 3.12 and higher.

##### Stable style
