On Feb 23, 2025, ElizaOS significantly enhanced its database capabilities by adding PGLite support alongside PostgreSQL and improved the Telegram agent's functionality with several bug fixes. These updates contribute to a more flexible database architecture and smoother operations across various components.

✅ Completed Work

Database & Core Enhancements

  • Added support for PGLite and PostgreSQL with an injectable connection manager pattern using Drizzle ORM, streamlining connection management. elizaos/eliza#3598
  • Replaced the AgentRuntime with its interface to allow for different types of AgentRuntime implementations. elizaos/eliza#2388
  • Removed the langchain dependency for text splitting, addressing issue #2917. elizaos/eliza#3642
  • Implemented non-critical turbo optimizations aimed at improving performance. elizaos/eliza#2503

Feature & Bug Fixes

  • Enabled fetching relevant facts in the facts provider by uncommenting and renaming code elements. elizaos/eliza#2635
  • Fixed the E2E test for Telegram by adding the chat attribute to the mocked message and resolving issues with group chat functionality. elizaos/eliza#3624
  • Addressed a bug related to generating structured objects and images with NEAR AI. elizaos/eliza#3644

Project Stability & Communication

  • Stabilized the develop branch. elizaos/eliza#3645
  • Updated the Discord link for ElizaOS. elizaos/eliza#3643
