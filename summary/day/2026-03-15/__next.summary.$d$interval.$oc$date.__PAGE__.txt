4:T64c,## Proposal: GNAP as a coordination protocol for ElizaOS multi-agent groups

ElizaOS is a full-featured platform for multi-agent AI development — groups of specialized agents, plugin system, connections to Discord/Telegram/Farcaster. As agent groups work on shared tasks, coordinating work across agents without conflicts is the key challenge.

[GNAP](https://github.com/farol-team/gnap) (Git-Native Agent Protocol) provides a minimal coordination layer: a shared git repo as a task board with `board/todo/` → `board/doing/` → `board/done/`. Any ElizaOS agent can participate via a GNAP plugin.

**Applied to ElizaOS multi-agent groups:**

A group of specialized Eliza agents working on a content creation pipeline:

```
board/todo/research-topic-ai-safety.md     ← Coordinator agent creates
board/doing/research-topic-ai-safety.md    ← Research agent claims
board/done/research-topic-ai-safety.md     ← Research committed with sources

board/todo/write-blog-post-ai-safety.md    ← Writer agent picks up
board/doing/write-blog-post-ai-safety.md
board/done/write-blog-post-ai-safety.md    ← Draft committed

board/todo/publish-to-social-media.md      ← Social agent publishes (Discord, Farcaster)
```

A `@elizaos/plugin-gnap` would expose GNAP board operations as Eliza actions: `CLAIM_TASK`, `COMPLETE_TASK`, `CREATE_TASK`. This integrates naturally with Eliza's plugin architecture and event-driven model.

Given ElizaOS's focus on autonomous agents for everyone, GNAP makes multi-agent coordination accessible — no infrastructure, just a git repo.
