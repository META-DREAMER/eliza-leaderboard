4:Taf7,### Problem

When an Eliza agent sends USDC or ETH through `IWalletService`, it has no signal about whether the recipient wallet is trustworthy. A fresh sybil wallet created 3 hours ago looks identical to a 6-month-old legitimate operator.

This matters more for autonomous agents than for humans — agents can't "eyeball" a wallet's history on a block explorer before sending money.

### Proposal

Add an optional pre-transfer reputation check using [DJD Agent Score](https://djd-agent-score.fly.dev), a free API that scores wallets on Base based on on-chain USDC transaction history.

This could be implemented as a skill or as a guard in the wallet service:

```typescript
// Skill: check wallet reputation before sending money
async function checkWalletReputation(wallet: string): Promise<{
  safe: boolean;
  score: number;
  tier: string;
  reason: string;
}> {
  const res = await fetch(
    `https://djd-agent-score.fly.dev/v1/score/basic?wallet=${wallet}`
  );
  const { score, tier, confidence, recommendation } = await res.json();

  return {
    safe: score >= 40 && confidence >= 0.2,
    score,
    tier,
    reason: score < 40
      ? `Low reputation (${score}/100, ${tier}) — wallet may be newly created or show suspicious patterns`
      : `Reputation OK (${score}/100, ${tier})`
  };
}
```

### What the scoring covers

The API analyzes real on-chain USDC transaction history and runs 12 behavioral checks:

- **Sybil detection** — closed-loop trading, puppet funding chains, coordinated wallet creation
- **Gaming detection** — wash trading, velocity spikes, balance window dressing
- **Identity signals** — account age, Basename registration, partner diversity
- **Reliability** — transaction consistency, payment patterns

Returns a 0–100 score with tier (New/Developing/Emerging/Established/Trusted), confidence level, and recommendation.

### Why this fits Eliza

- **Free tier**: 10 calls/day, no API key, no signup — zero friction for agent developers
- **Fast**: <200ms response, cached scores
- **TypeScript native**: Simple `fetch()` call, typed responses
- **On-chain data only**: No off-chain identity required — works for any wallet on Base
- **Eliza's wallet system**: Agents using `IWalletService` to send transactions can check recipients before transferring

### Try it

```bash
curl "https://djd-agent-score.fly.dev/v1/score/basic?wallet=0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"
```

Returns:
```json
{
  "score": 68,
  "tier": "Established",
  "confidence": 0.49,
  "recommendation": "proceed_with_caution"
}
```
