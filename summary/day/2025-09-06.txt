14:T97f,## Feature Request

### Problem
Agents currently cannot fetch and analyze web content when users share URLs. This limits their ability to:
- Summarize articles and documentation
- Extract information from web pages
- Analyze content from provided links
- Access up-to-date information from websites

### Current Workarounds
Currently, to enable web fetching, users must:
1. Configure MCP (Model Context Protocol) servers like `@modelcontextprotocol/server-fetch` or `firecrawl-mcp`
2. Add the MCP plugin to their agent configuration
3. Set up environment variables and API keys (for some services)

This adds complexity and external dependencies for what should be a basic capability.

### Proposed Solution
Add native web fetching capability to ElizaOS agents through one of these approaches:

**Option 1: Built-in Action**
- Add a `FETCH_WEBPAGE` action to the bootstrap plugin
- Action would fetch URL content, convert HTML to markdown, and summarize
- Could use the LLM to extract relevant information based on context

**Option 2: Dedicated Plugin**
- Create `@elizaos/plugin-browser` or `@elizaos/plugin-web`
- Provide actions for fetching, scraping, and analyzing web content
- Could include advanced features like JavaScript rendering, screenshot capture

**Option 3: Provider Enhancement**
- Add web fetching as a provider that supplies web content to the agent's context
- Could automatically detect URLs in messages and fetch content

### Benefits
- Agents can access and analyze web content directly
- Better user experience without complex configuration
- Reduced dependency on external services
- More natural interactions when users share links

### Example Use Cases
- User shares article link → Agent summarizes key points
- User asks about documentation → Agent fetches and explains relevant sections
- User shares product page → Agent extracts specifications and reviews
- User provides research paper → Agent analyzes methodology and findings

### Technical Considerations
- Security: Need to handle URL validation, timeouts, content size limits
- Performance: Consider caching fetched content
- Privacy: Respect robots.txt and user-agent policies
- Format: Convert HTML to markdown for better LLM processing

### Related Issues/PRs
- MCP plugin provides this through external servers but requires additional setup
