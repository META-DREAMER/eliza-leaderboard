## Key Technical Approach

Uses CSS `display: contents` to make Streamdown's wrapper divs "transparent" to layout:

```css
.markdown-content > div {
  display: contents !important;
}
```

This removes wrapper divs from the box tree while preserving DOM structure and semantics, eliminating the spacing contribution from Tailwind's `space-y-4` class.
